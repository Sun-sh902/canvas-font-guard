Scope and limitations

In Canvas 2D and OffscreenCanvas, matching font names are replaced with a nonexistent internal family name so the browser uses a normal fallback from the candidate font stack. Matching fonts are also filtered from local font enumeration results when the API is available.

This does not uninstall system fonts, and it does not cover DOM/CSS font measurement, unknown font names, WebGL, or every Canvas image readback path. Pages may detect the extension itself.

Permissions are requested when you enable global or per-site protection; granted permissions remain when protection is turned off. You can revoke them in Chrome's extension settings.
